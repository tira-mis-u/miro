# antiwhite

**antiwhite** is a visual collaboration workspace built around an infinite canvas.

It is designed for people to **think, design, explain, explore, and organize ideas visually** rather than being limited to rigid documents or predefined layouts. The canvas acts as a flexible workspace where different kinds of visual content can coexist and evolve together.

antiwhite can be used for a wide range of visual work, including sketching ideas, creating diagrams, planning systems, explaining concepts, mapping information, organizing research, and collaborating on shared work. Simple elements can be combined into more structured visual compositions without forcing the user into a fixed workflow.

The core idea is simple:

> **Give people a visual space where ideas can be created and connected freely.**

Rather than treating the canvas as a collection of isolated tools, antiwhite treats it as a continuous workspace. Drawing, structure, spatial relationships, and collaboration are parts of the same environment, allowing the user to move naturally between rough exploration and more organized visual work.

## Philosophy

antiwhite is built around a few principles:

- **Canvas first** — the workspace is the primary interface, not a collection of separate pages.
- **Visual thinking** — information should be easy to express through space, structure, and relationships.
- **Direct manipulation** — objects should behave naturally when created, selected, edited, and transformed.
- **Flexible structure** — the system should support both quick sketches and more structured work without forcing either one.
- **Low friction** — common actions should remain simple and predictable.
- **Collaboration** — ideas should be able to evolve in a shared workspace.

## What antiwhite is

antiwhite sits somewhere between a whiteboard, diagramming workspace, and visual thinking environment.

It is intentionally open-ended: the same canvas can be used for a quick sketch, a system diagram, a visual explanation, a planning board, or a more structured composition.

The specific tools and capabilities can evolve over time, but the purpose remains the same:

**a flexible visual workspace for turning ideas into something you can see, manipulate, connect, and develop.**
